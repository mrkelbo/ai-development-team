# AI Development Team — private Claude Code marketplace

Contains a **single cross-project plugin** at `plugins/ai-development-team/` and a marketplace catalog at `.claude-plugin/marketplace.json`.

- **Read first:** `plugins/ai-development-team/README.md`
- **Ten agents:** `plugins/ai-development-team/agents/*.md`
- **Rules:** `plugins/ai-development-team/standards/`
- **Workflows:** `plugins/ai-development-team/skills/`
- **Templates:** `plugins/ai-development-team/templates/`
- **Native validation on a machine with Claude Code:** `claude plugin validate .` and `claude plugin validate ./plugins/ai-development-team`.
- **Local static validation:** `python scripts/validate_package.py`.

This directory is ready to be put in a Git repository. It is not yet connected to your GitHub account and is not installed into your local Claude Code environment by this file creation.
